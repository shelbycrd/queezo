# Queezo — AI Project Context

## Project Overview

Queezo is a student-focused productivity and learning platform.

## Current Applications

- App 1: Flashcards — two-sided flashcards for studying.
    
- App 2: GWA Calculator — calculates weighted grades based on grades and course units.
    
- App 3: Pomodoro Timer — study and break timer.
    

## Authentication

- The project has a login system.
    
- Account registration has been implemented through a CLI workflow.
    
- Website-based account registration and anti-abuse measures are planned or under development.
