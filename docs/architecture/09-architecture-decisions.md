# 09 · Architecture decisions and tradeoffs

[Architecture index](README.md) · [Verification and limitations](VERIFICATION.md)

The records below describe current design choices. Historical rationale is identified only where repository evidence supports it.

| Decision | Implementation and evidence | Consequence |
| --- | --- | --- |
| Vue SPA and FastAPI APIs | Vue 3, Vue Router, and Vite serve feature views. FastAPI routers, Pydantic schemas, and SQLAlchemy group backend responsibilities. The rationale for selecting the original frameworks is undocumented. [Frontend dependencies](../../frontend/package.json), [backend dependencies](../../backend/requirements.txt), [API assembly](../../backend/app/main.py) | Inferred benefit is a lightweight browser build and explicit API validation. The browser and backend must coordinate route and session contracts. |
| Separate GWA entrypoint | The GWA service shares authentication reads, but calculates in request scope and never stores grade inputs. [GWA entrypoint](../../backend/app/gwa/main.py), [Compose](../../compose.yaml) | Inferred benefit is a narrow service boundary. Deployments still coordinate startup and database compatibility. |
| SQLite with short, serialized writes | WAL, foreign keys, busy timeout, and immediate transactions. Slow Argon2 and model work occur outside write transactions. [Connection setup](../../backend/app/database.py), [reliability notes](../production/DATABASE_RELIABILITY.md) | Simple durable storage on one host. Competing writes remain serialized. Backup, restore, and disk durability are operational prerequisites. |
| Shared cache, session-owned snapshots | Card-level cache with generation identity, source fingerprints, and fenced leases is reused by solo and room preparation. Question snapshots own shuffled options, IDs, and grading state. [Cache implementation](../../backend/app/services/distractor_cache.py), [shared distractor findings](../quality/SHARED_DISTRACTORS.md) | Repeat inference drops and in-progress questions stay stable. Dependency tracking and migration maintenance are required. |
| Bound expensive inference | Model slot, persisted per-card claim, bounded solo queue and runtime timeouts, adaptive retries, and fallback. [Generator](../../backend/app/services/distractors.py), [solo worker](../../backend/app/services/multiple_choice.py), [room worker](../../backend/app/services/room_study.py) | Cached work can bypass model latency. A cold prefix or slow model can delay study. Slot coordination is process-local; database leases fence a card across workers. |
| REST writes and WebSocket snapshots for rooms | Mutations use CSRF-protected REST. SQLite owns durable state. Sockets authenticate and repeatedly project viewer-specific snapshots. [Room API](../../backend/app/routers/study_rooms.py) | Viewer privacy and idempotency rules remain centralized. Polling work grows with connected sockets. Process-local presence registration and notification wakeups constrain horizontal scaling. |
| Cookie sessions, explicit scope checks | Hashed opaque session tokens, trusted Origin and CSRF, owner-bound rows and revalidated share grants, room membership checks. [Middleware](../../backend/app/auth/middleware.py), [auth dependencies](../../backend/app/auth/dependencies.py), [room service](../../backend/app/services/study_rooms.py) | Same-origin browser operations are simple. Deployment needs correct proxy/HTTPS trust. Revocable share sessions require fresh access checks. |
| Browser-local Pomodoro | Countdown, phase, settings, and tasks in account-scoped local browser state. Completion optionally reports activity. [Timer service](../../frontend/src/services/pomodoro.js) | Timer can keep local state without a server job. Data is device/browser scoped and background execution depends on browser capabilities. |

## Open risks and operational limits

- Cold model timing and distractor quality depend on the host model and input. The current chat request leaves model residency to Ollama's defaults. Cache validation cannot certify an answer semantically. [Performance](../quality/PERFORMANCE.md), [distractor findings](../quality/SHARED_DISTRACTORS.md)
- The base stack binds to loopback. Production TLS, external proxy addresses, public allowlists, and real gateway cookie behavior need environment validation. [Deployment](07-deployment-and-infrastructure.md)
- Shared SQLite and the embedded workers are designed around one deployment. Measure lock pressure, connection polling, and failure recovery before adding replicas or public load. [Database design](03-database-design.md), [room QA](../quality/STUDY_ROOMS_QA.md)
- An interrupted deployment or disk loss needs off-host snapshots and a practiced restore. An external backup repository, alert coverage, and a drill are environment-specific. [Recovery runbook](../production/DATABASE_RELIABILITY.md)
- Email verification and account verification delivery are incomplete. Profile reporting is handled operationally through CLI review. [Authentication and security](04-authentication-and-security.md)
