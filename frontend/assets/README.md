# Visual assets

- `queezo-cloud.svg`: original Queezo study-cloud mark used by the home link and Home banner.
- `fonts/Quicksand.ttf`: unmodified variable font from the [Google Fonts Quicksand directory](https://github.com/google/fonts/tree/main/ofl/quicksand), downloaded November 18, 2026. The accompanying license is `fonts/OFL-Quicksand.txt`.

The font and illustration are served locally with the frontend. The UI does not request Google Fonts at runtime. The two supplied design references informed the palette, rounded surfaces, typography, and sidebar treatment; their images were not embedded into application pages.
